# RFC-002｜风格提取功能

## 提出背景

创作者经过一定周期的写作后，产生了从已完成作品中提取写作风格的诉求。

目前典阁已有「创作体系 → 风格指南」目录，但缺乏系统化的风格提取流程：没有定义如何选取样本、如何输出风格画像、如何校准，以及如何与入典流程衔接。

---

## 核心问题

如何在不破坏现有入典流程的前提下，新增一条「批量文章 → 多维风格画像 → 入典沉淀」的路径。

---

## 当前确认

经与创作者讨论，以下设计已确认：

### 两条路径

| 路径 | 输入 | 用途 |
|------|------|------|
| **自我分析** | 创作者自己的已完成卷（5-10份） | 看清自己的写作模式演化 |
| **外部作者分析** | 提供的外部文章链接/内容（5-10份） | 研究他人风格、学习参考 |

两条路径共享相同的输出格式，但 source 字段区分来源。

### 多维输出

风格画像不合并为单一文件，而是按维度拆分为独立典阁条目：

- **语言特征**：句式长度分布、词汇密度、高频词、标点使用习惯
- **结构模式**：开头方式、段落节奏、论证/叙事结构偏好
- **语气倾向**：正式度、情绪强度、第一/第三人称使用、修辞手法
- **书写习惯**：段落长度、标题风格、引用习惯、链接使用

此拆分允许创作者只更新某个维度而不影响其他。

### 校准机制

Agent 输出的风格画像是**草稿**，不是最终版本。创作者必须逐维度审核、修正、确认后，才正式入典。未经校准的画像不进入典阁。

### 复盘周期

建议每月复盘一次（基于日更频率）。Agent 不自动触发，由创作者手动发起：「风格复盘」。

---

## 设计假设

1. 风格提取不需要独立 Workflow，而是 Canonize（入典）的一个扩展触发分支
2. 风格画像的存储位置：典阁 → 创作体系 → 风格指南
3. 每次复盘生成新版本画像，覆盖旧版本（与 Current Context 覆盖逻辑一致）
4. 外部作者分析仅用于学习参考，明确标注来源

---

## 当前未解决的问题

- 风格画像是否需要版本记录（保留历史画像 vs 只保留最新）？
- 外部作者分析是否应独立于典阁（例如单独放在「境」的某个位置）？
- Agent 分析风格的一致性——不同 Agent 可能输出不同质量的分析，是否需要最小质量标准？

---

## 后续计划

1. 创建风格提取 Convention，定义输出格式与校准流程
2. 更新典阁使用方式，新增「路径四：风格提取」
3. 首次执行风格提取（创作者选择样本），验证流程
4. 根据首次执行反馈，调整 Convention 细节
