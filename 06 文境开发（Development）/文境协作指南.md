# 文境协作指南

> 面向测试者与合作者的 Vault 同步与更新说明

---

## 首次获取

```bash
git clone https://github.com/CyberBrain1721/wenjing-vault.git "文境vault/文境Vault"
```

Clone 后在 Obsidian 中打开该目录作为 Vault。

---

## 日常更新

```bash
cd 文境vault/文境Vault && git pull origin main
```

拉取后在 Obsidian 中刷新即可看到最新内容。

---

## Vault 结构速览

| 层 | 目录 | 用途 |
|----|------|------|
| 道 | `01 悟道（系统）/` | 系统原则、门训、总纲 |
| 境 | `02 养境（知识）/` | Inbox、典阁、知识索引 |
| 卷 | `03 成卷（项目）/` | 已完成的创作项目 + 境·回溯 + 境·发布日志 |
| 归藏 | `05 归藏（存档）/` | 历史版本归档 |
| 典阁 | `02 养境（知识）/02 典阁/` | 已验证的长期知识资产 |
| 开发 | `06 文境开发（Development）/` | 协议、规范、架构评审、日志 |
| Agent | `04 Agent入口/` | Agent 初始化协议链 |
