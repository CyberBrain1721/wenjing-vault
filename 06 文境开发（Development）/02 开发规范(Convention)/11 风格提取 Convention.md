# 风格提取 Convention

本 Convention 定义风格提取的触发条件、样本选取、输出格式、校准流程及入典规则。

---

## 一、触发条件

创作者说以下任意内容时，进入风格提取流程：

- 「风格提取」
- 「分析我的写作风格」
- 「风格复盘」
- 「分析 [作者名] 的写作风格」

---

## 二、样本选取规则

### 自我分析

1. Agent 列出创作者所有已完成卷（`03 成卷（项目）/` 下所有目录）
2. 创作者选择 5-10 份作为分析样本
3. 样本应为完整文章（正文），而非创作过程草稿

### 外部作者分析

1. 创作者提供 5-10 篇文章的链接或内容
2. Agent 通过 Capture Workflow 收录内容（仅索引或摘要，不需全文存档）
3. 收录完成后进入风格分析

---

## 三、分析维度

Agent 按以下四个维度分别输出风格画像，每个维度为一个独立典阁条目：

### 维度一：语言特征

| 指标 | 说明 |
|------|------|
| 平均句长 | 按字数统计句长分布 |
| 句式偏好 | 长句/短句比例，复合句频率 |
| 词汇密度 | 实词占比、低频词使用 |
| 高频词 Top 20 | 排除停用词后的高频词列表 |
| 标点习惯 | 破折号、省略号、分号等使用频率 |
| 段落长度 | 平均段落字数及分布 |

### 维度二：结构模式

| 指标 | 说明 |
|------|------|
| 开头方式 | 提问式/陈述式/引用式/故事式等分布 |
| 段落节奏 | 长段-短段交替模式 |
| 论证结构 | 归纳/演绎/类比/对比的偏好 |
| 结尾方式 | 总结式/开放式/呼应收尾/金句收束 |
| 篇幅控制 | 各文章的总体字数范围 |

### 维度三：语气倾向

| 指标 | 说明 |
|------|------|
| 正式度 | 口语化 ↔ 书面化的光谱位置 |
| 情绪强度 | 冷静克制 ↔ 情感充沛 |
| 人称使用 | 第一/第二/第三人称的频率 |
| 修辞手法 | 比喻、排比、反问等使用模式 |
| 读者距离 | 亲近/疏离/对话感/说教感 |

### 维度四：书写习惯

| 指标 | 说明 |
|------|------|
| 标题风格 | 短标题/长标题/问句式/陈述式 |
| 段落首句 | 主题句前置/悬念式/过渡式 |
| 引用习惯 | 引用频率、引用来源类型 |
| 加粗/强调 | 强调标记的使用频率和位置 |
| 空行节奏 | 段落间的空白使用模式 |

---

## 四、输出格式

每个维度生成一个独立的典阁条目。文件命名：

```
【风】[创作者名/作者名] · [维度名称] · [分析日期].md
```

示例：
```
【风】文境 · 语言特征 · 2026-07.md
【风】文境 · 结构模式 · 2026-07.md
【风】文境 · 语气倾向 · 2026-07.md
【风】文境 · 书写习惯 · 2026-07.md
```

### YAML Frontmatter

```yaml
---
type: 风
status: 草稿 | 已校准
source: self | external
source_author: （外部作者名，self 时删除此行）
source_volumes: [[卷020]] [[卷018]] [[卷015]] ...
sample_count: 8
analysis_date: 2026-07
confidence: low | medium | high
---
```

### 正文结构

```markdown
# 【风】[名称] · [维度]

## 分析样本
（列出所有来源卷/文章名，含 wikilink）

## 数据总览
（该维度的总体统计）

## 详细分析
（逐指标展开，每个指标包含：数据 → 观察 → 示例）

## 变化趋势
（如有历史画像，对比变化；首次分析则写「首次提取，无可对比数据」）

## 校准记录
（创作者审核后的修正内容，逐条记录）
```

---

## 五、校准流程

1. Agent 输出草稿（`status: 草稿`），逐维度呈现
2. 创作者审核每个维度，提出修正意见
3. Agent 根据修正更新画像
4. 创作者确认 → `status` 改为 `已校准`
5. 正式入典，存入 `典阁/创作体系/风格指南/`

**重要**：未经校准的画像不入典。Agent 不得将 `status: 草稿` 的文件直接放入典阁。

---

## 六、复盘与更新

| 写作频率 | 建议复盘周期 |
|----------|------------|
| 日更 | 每月一次 |
| 周更 | 每季度一次 |
| 不定期 | 每完成 10 篇后 |

复盘时：
1. 加入新完成的卷作为补充样本
2. 重新生成风格画像
3. 与上一版对比，标注变化
4. 覆盖更新典阁中的对应条目

## 八、Agent 执行约束

1. **只呈现，不评价**：画像反映「是什么」，不是「好不好」。禁止使用「句式过于单一」「词汇不够丰富」等评判性语言
2. **允许创作者推翻任何结论**：Agent 的分析基于统计模式，创作者对自己风格的认知高于统计
3. **明确标注数据来源**：每个结论必须标注来自哪些样本文章
4. **区分信号与噪音**：样本数少于 5 份时，标注 `confidence: low`，说明结论可能不稳定
