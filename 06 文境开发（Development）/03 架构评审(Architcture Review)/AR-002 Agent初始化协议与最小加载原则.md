

## 评审背景

随着文境开始接入 Hermes、WorkBuddy 等桌面 Agent，一个新的问题逐渐显现。

过去，Agent 接入文境的方式通常是直接读取整个 Vault，并根据自身理解决定后续行为。

这种方式适用于传统知识库，但并不适用于文境。

文境并非普通知识库，而是一套具有明确工作流程的人机协作系统。

如果 Agent 在进入文境后立即索引整个 Vault，不仅会增加初始化成本，也会降低上下文质量，并导致不同 Agent 产生不同的理解方式。

因此，本次评审围绕 Agent 初始化流程重新设计文境入口协议。

---

# 问题一

## Agent 是否应该直接读取整个 Vault

最初方案认为，Agent 在接入文境后，应首先读取整个知识库，再开始工作。

经过分析后发现，这种方式存在三个问题。

第一，随着文境不断发展，Vault 将持续增长，初始化成本会越来越高。

第二，大量与当前任务无关的文档会提前进入上下文，降低 Agent 对当前工作的关注度。

第三，不同 Agent 对文档的理解方式不同，容易导致初始化结果不一致。

因此，本次评审否定了"全量加载"方案。

Agent 不应主动索引整个 Vault。

---

# 问题二

## Agent 是否应该自行判断下一步

另一种方案认为，Agent 可以根据用户输入，自主判断进入创作或开发流程。

进一步推导后发现，这意味着工作流程由 Agent 决定，而不是由文境协议决定。

不同模型可能得到不同结果。

系统行为将失去一致性。

因此，本次评审决定：

工作流程不由 Agent 推断。

工作流程由协议明确规定。

Agent 负责执行协议，而不是决定协议。

---

# 问题三

## 文境是否需要统一初始化流程

为了保证不同 Agent 拥有一致的接入方式，本次评审正式建立 Agent 初始化协议链（Protocol Chain）。

所有 Agent 均应按照统一流程进入文境。

协议链如下：

文境入口（Protocol）

↓

工作模式确认（Mode Selection）

↓

对应入口（Entry）

↓

目标模块初始化

↓

等待任务

整个初始化过程采用协议驱动，而不是模型推理。

---

# 问题四

## 共创模式是否需要读取全部系统文档

在设计共创入口时，我们进一步讨论了初始化所需的文档范围。

如果加载全部系统文档，将造成上下文冗余，并增加启动成本。

因此，本次评审建立"最小初始化原则（Minimal Initialization Principle）"。

Agent 在进入共创模式后，仅加载完成当前工作所必须的核心协议。

当前初始化链确定如下：

AI 阅读原则

↓

文境总纲

↓

文境系统约束

↓

道说明

↓

等待创作者任务

除上述文档外，其余内容均采用按需加载。

---

# 问题五

## 是否需要建立按需加载机制

随着文境持续发展，系统文档将不断增加。

如果所有内容均在初始化阶段读取，Agent 的上下文质量将持续下降。

因此，本次评审正式引入按需加载（Lazy Loading）原则。

Agent 仅加载完成当前阶段所必须的文档。

后续内容根据实际任务继续读取。

初始化负责建立协作环境。

具体任务负责决定后续加载内容。

---

# 架构收敛

经过本次评审，文境正式建立统一的 Agent 初始化架构。

Agent 不直接读取整个 Vault。

Agent 不主动决定工作流程。

Agent 不根据经验推断下一步。

所有初始化过程均由协议节点驱动。

每一个协议节点只负责完成一个动作。

完成后进入下一节点。

直到进入 Ready 状态。

---

# 本次评审结论

本次评审形成以下正式结论：

一、Agent 不主动索引整个 Vault。

二、Agent 不自行推断工作模式。

三、所有 Agent 统一采用 Protocol Chain 完成初始化。

四、共创模式采用最小初始化原则。

五、系统采用按需加载（Lazy Loading）机制，而非全量加载。

六、协议负责流程，Agent 负责执行。

---

# 对系统的影响

本次评审属于 Agent Runtime 的基础架构调整。

后续所有 Agent（包括 Hermes、WorkBuddy、Claude Desktop 及其他未来 Agent）均应遵循统一初始化协议。

任何新增工作模式，也应继续采用：

工作模式确认

↓

对应入口

↓

协议初始化

↓

等待任务

不得绕过初始化协议直接进入系统。

---

# 后续验证

本次评审完成后，将进入 Hermes 接入测试阶段。

重点验证以下问题：

Agent 是否能够严格按照协议节点执行初始化。

Agent 是否能够停止主动索引整个 Vault。

Agent 是否能够根据协议完成模式切换。

Agent 是否能够在最小初始化条件下完成后续协作。

根据测试结果，再决定是否进入正式 Runtime 设计阶段。
