# 创作过程：缝隙与自反

## 起点

从"缝隙款产品的要点，以及它是怎么被发现的"这个追问开始，展开为四层递进：缝隙款定义 → 真需求识别五问题框架 → 框架的论证基础 → 回照文境自身。

## 标题选择

三个方向：

1. 《缝隙款产品：如何找到一个足够窄、足够真的问题》——实用方法论
2. 《你的痛，是需求还是执念——一个五问题自我检验框架》——决策工具
3. 《缝隙与自反：从真需求识别到文境的存在理由》——自我审视

选择方向 ③。理由：以文境自反为落点，前四章为推导过程。入口窄，深度大，符合"第一个念头永远是人的"这一核心原则在方法论层面的外显。

## 结构确认

```
一、缝隙款产品：窄而锋利
二、缝隙的发现：五条路径
三、五问题：从"我痛"到"真的有人痛"
四、这框架凭什么让人信
五、回到文境：用框架照自己
```

结构确认后一次性生成全文，humanizer 终审。

## 框架来源

对话中归纳的"五问题框架"来源：
- Eric Raymond 的 Itch 原则（1997）
- Christensen 的 Jobs to Be Done（2003–2016）
- Kahneman 的显示偏好理论（行为经济学）
- Pieter Levels 等人的独立开发者经验

## 关键发现

文境自反结果：三七开。真需求三（自己痛、剥离后成立、问题独立存在），疑问七（拼凑方案小众、付费意愿勉强）。

五问题框架没覆盖的维度：认知成本 / 范式翻译问题——不是你识别了需求就够了，你还需要让人理解这个需求为什么重要。对范式型产品而言，这是比需求识别更深的问题。
