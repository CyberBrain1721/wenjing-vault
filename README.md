# 文境 · Wenjing

> 一套协议驱动的 AI 协作创作系统（Creative Operating System），基于 Obsidian Vault 构建。
>
> 版本：v0.2.0（共创和开发版）

文境不是写作软件，也不是内容模板。

文境的目标不是帮助 AI 创作，而是帮助创作者建立、积累、沉淀并延续自己的创作世界。

**文境服务于创作者，而非作品。**

---

## 为什么是文境

传统创作工具的假设是"工具帮你完成作品"；文境的假设是"系统帮你完成一生的创作"。

- 灵感不丢失：任何想法先进入藏阁（Inbox），不判断价值，先留存。
- 知识不混淆：文境管理知识，卷管理作品，两者边界固定。
- 经验可沉淀：每完成一卷，方法论与风格回归于境，反哺下一卷。
- 流程可复用：所有协作行为由协议驱动，不依赖某个具体 AI 的临场发挥。

---

## 核心特性

- **三层架构**：道（原则与信念）→ 境（知识积累）→ 卷（具体作品）
- **协议驱动（Protocol-Driven）**：Agent 不主动决定流程，协议决定流程；Agent 负责执行协议
- **生命周期循环**：`道 → 境 → 卷 → 境 → 道`，永不终止
- **知识/作品分离**：所有正式知识必须进入「境」，所有临时创作仅属于对应「卷」
- **五类工作流（Workflow）**：Capture（收录）、Organization（整理）、Archive（归档）、Canonize（入典）、Reflection（反思）
- **AI 观察者原则**：AI 拥有建言权，不拥有裁决权；创作者始终保留最终解释权
- **双模式协作**：共创模式（Creator Mode）服务于创作，开发模式（Development Mode）服务于系统自身演化

## 快速开始

### 前置要求

- [Obsidian](https://obsidian.md/)（推荐 1.4+，启用"属性（Properties）"功能）
- 一个 AI 协作客户端（任意支持读取 Vault 文件的 Agent）

### 安装

```bash
git clone https://github.com/CyberBrain1721/wenjing-vault.git
```

用 Obsidian 打开仓库目录作为 Vault。

### 进入文境

1. 阅读仓库根目录 `AGENTS.md` —— 它是 Agent 的入口引导。
2. 让 Agent 读取 `04 Agent入口/00 文境入口.md`，按协议完成初始化。
3. 在「工作模式确认」中选择本次工作模式：
   - **① 共创模式（Creator Mode）**：作品创作、灵感讨论、知识整理、项目推进
   - **② 开发模式（Development Mode）**：系统开发、协议修改、架构评审、Bug 修复

## 工作原理

### 三层架构

| 层 | 职责 | 生命周期 |
|---|---|---|
| 道 | 记录信念、原则、制度与演化 | 长期稳定 |
| 境 | 积累灵感、设定、资料、经验、方法 | 永不结束 |
| 卷 | 承载具体作品（小说、剧本、文章、设定集…） | 可以结束 |

### 文境循环

```
道 → 境 → 卷 → 境 → 道
```

- 道指导境
- 境孕育卷
- 卷完成后，经验回归于境
- 境不断成长，最终反哺于道

### 权责划分

| 角色 | 权利 |
|---|---|
| 文境之主（创作者） | 最终裁决权：决定方向、制度，决定是否采纳建议 |
| AI | 建言权：分析、建议、执行、检查；不得擅自修改制度 |
