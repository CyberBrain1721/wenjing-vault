# 文境协作指南

> Agent 可读。面向协作者与 Agent 自身的 Vault 同步说明。

---

## 本质

文境是一个本地 Obsidian 创作系统。

它不依赖 Codex、WorkBuddy、OpenClaw 或任何单一人工智能环境。

所有 Agent 只是接入者。

接入后必须读取统一入口：

```text
04 Agent入口/00 文境入口.md
```

然后按照文境协议开启协作。

## 协作者

### 首次获取

```bash
git clone https://github.com/CyberBrain1721/wenjing-vault.git "文境vault/文境Vault"
```

Clone 后在 Obsidian 中打开该目录作为 Vault。

### 日常更新

```bash
cd 文境vault/文境Vault && git pull origin main
```

---

## Agent 自更新

当创作者要求「更新文境」「同步最新版」「pull 最新协议」时，Agent 应：

```bash
cd "E:/文境vault/文境Vault" && git pull origin main
```

拉取后 Agent 需重新读取入口协议链（`00 文境入口` → 模式选择），因为协议可能已变更。

## Vault 结构速览

| 层 | 目录 | 用途 |
|----|------|------|
| 道 | `01 悟道（系统）/` | 系统原则、门训、总纲 |

| 归藏 | `05 归藏（存档）/` | 历史版本归档 |
| 典阁 | `02 养境（知识）/02 典阁/` | 已验证的长期知识资产 |
| 开发 | `06 文境开发（Development）/` | 协议、规范、架构评审、日志 |
| Agent | `04 Agent入口/` | Agent 初始化协议链 |

## 版本

当前：v0.2.0

版本依据：

- 加入 `境·回溯`：Agent 进入 Conversation Runtime 前，应检查创作者原生风格材料。
- 加入统一 Agent 接入原则：Codex、WorkBuddy、OpenClaw 或其他 Agent 均从同一入口启动。
- 补齐 Capture 入口协议：`Capture Convention`、`Inbox Standard`、`Knowledge Map Convention`。
