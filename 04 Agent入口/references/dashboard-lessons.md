# 看板使用说明

## 文境看板

`文境看板.html` 为深色主题仪表盘，建议用浏览器打开。

显示的六张卡片：入境 / 道 / 藏阁 / 典阁 / 卷 / 归藏，反映各层当前状态。

## 文境速览

`文境速览.canvas` 为 Obsidian 原生 Canvas 文件，可在 Obsidian 内直接打开。

三区域各最多显示 3 条：最新成卷 / 藏阁各状态 Inbox / 典阁最新入典。

## 数据刷新

看板和速览的数据通过扫描 Vault 实际文件生成。当 Vault 内容变化后，需要重新生成以更新数字和链接。

## 链接规范

看板内跳转使用 `obsidian://open?vault=VAULT_NAME&file=PATH` 格式，由操作系统处理协议，不受插件沙箱限制。
