# 发布日志格式化标准

成卷正文必须严格遵循此格式。

## 分区
- 禁用 `#` `##` `###` 等 Markdown 标题
- 仅用 `> **粗体引用块**` 作为一级分区标识
- 引用块后空一行，然后接正文

## 缩进
- 一级正文：4 个空格缩进
- 二级子标题：8 个空格缩进 + `**粗体**`
- 二级正文：8 个空格缩进
- 结尾段落：4 或 7/8 个空格缩进均可

## 段落
- 长段落优先——一句接一句，不靠频繁换行呼吸
- 短句单独成段仅用于：核心论点、转折点
- 段落之间空一行

## 字体
- 粗体仅用于两类：分区标题、全文核心概念（2-3 处）
- 不用斜体、不用删除线

## 标点
- 全宽中文标点：`，` `。` `——` `"`
- 不用半角标点混入中文

## 结尾
- 不用"所以""综上所述""因此"
- 可加"亲爱的"等直接称呼
- 落在具体画面或一句话上，不升华为哲理总结

## 示例

```
> **平静是一种力量**

    在纷繁复杂的世界里沉淀思考，于波澜不惊里积蓄力量。

> **三种自然的告别**

        **写一封不给任何人看的信。**

        写给那个执念——把它当成一个你认识很久的人。

        **换一个地方看同一个执念。**

        执念在熟悉的环境里会自动续命。

    亲爱的，过去的自己不需要消失。

    他在那个时候已经尽了全力。现在你长大了，可以让他休息了。
```
