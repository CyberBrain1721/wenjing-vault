# 中文平台内容抓取指南

## 适用场景

知乎、简书、百家号等中文内容平台使用强反爬机制（JS challenge、登录墙），常规 HTTP 请求通常被拦截。

## 通用策略

### 优先：浏览器自动化

通过操控用户本地已登录的浏览器获取页面内容，利用已有的登录态和 Cookie 绕过反爬。

各 Agent 平台通常提供对应的浏览器操控工具（如桌面自动化、浏览器扩展等），具体命令请参考当前 Agent 平台的文档。

### 降级：手动粘贴

当自动化路径不可用时，请创作者手动复制粘贴正文内容。

## 降级链

```
HTTP 请求 (1次) → 浏览器自动化 (1次) → 手动粘贴 → 放弃该篇
```

同一 URL 不在同一个阻塞层级反复重试。

## 文章边界识别

自动化提取通常返回完整页面文本（含导航、评论区、推荐阅读）。文章正文位于标题行和发布时间行之间，Agent 需自行识别并截取。
