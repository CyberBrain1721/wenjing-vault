# 【念】AI学习路线 — 四门必跟课程

四门 AI 必修课，对应四类人：

1. 吴恩达《AI for everyone》— 看到 AI 焦虑，但完全不知道从哪开始
2. 李宏毅《机器学习大模型》— 会用 ChatGPT，但想知道它为什么能回答
3. 李沐《动手学AI》— 上课听懂了，但动手就卡壳
4. Karpathy《AI 底层逻辑》— 想理解 AI 的本质限制，不只是会调 API

从轻到重，逐步深入。
