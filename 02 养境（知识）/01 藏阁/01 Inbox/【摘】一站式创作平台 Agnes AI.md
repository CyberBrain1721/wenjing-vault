## Original Content

### 引言

3周前发现了 Agnes AI。当时它把文本、图片、视频三个核心模型 API 全部免费开放，文本模型一周被调用了1万亿 Token。3周后最新数据：单周调用量 5万亿 Token。图片模型一周生成了 567万张图。视频模型一周生成了 237万秒（约650多个小时）的成片。免费策略撬动了大量创作者和开发者。Agnes AI 本周推出了新产品：Pavo。

### 01: Pavo 是什么？

这是一个 PC 端的 AI 创作平台。核心功能：将图片生成、视频生成、短剧创作集成在一个工作流中，并由一个 Agent 当总指挥。核心模块：

- Agent：一句话下需求
- 图片生成：海报、商品图、写真
- 视频生成：文生视频、图生视频
- 剧情短片：从剧本到成片的短剧工作流

优势：无需切换工具，从想法到成片在一个浏览器里完成。

### 02: 剧情短片：从一句话到一条短剧

这是 Pavo 区别于其他 AI 工具的核心功能。Pavo 把自研的免费多模态模型放到产品里，可以直接免费使用。

生产流水线：剧本创作 → 人物和场景设定 → 分镜设计 → 视频生成 → 成片渲染

适用场景：热点短剧、职场轻喜剧、情侣剧情、萌宠拟人、品牌剧情广告。

测试示例：输入指令"晴朗的天空突然变暗，然后又大大小小的飞碟，宇宙飞船、战舰在天空中飞过，很远但是看起来很震撼。最后其中一个最大的母舰突破云层和远处的大山相撞了。"

Pavo 工作流程：
1. 确认需求（视觉风格、时长等）
2. 自动撰写剧本草稿（用户只需确认）
3. 设计角色、场景和相关道具（细化丰富）
4. 生成角色、场景相关配图（用户确认是否符合预期）
5. 写分镜脚本（拆解成多幕，详细说明运镜、画面、台词）
6. 为每个分镜设计关键帧
7. 生成分镜视频
8. 一键合成

注意事项：不满意可提前调整，需要人工介入。目前难以达到电影级质感。

### 03: Agent：一句话跑完一条广告片

Pavo Agent 基于自研的 Harness 框架制作。工作方式：用户用一句话描述需求，Agent 自主规划步骤、调模型、出素材。

示例："> 帮我为一款香水做一张商业海报和一条 15 秒广告视频"——Agent 收到后自行拆解任务，用户无需干预。

关键特性：上下文记忆。支持多轮对话调整，无需每次重复描述项目背景。

### 04: 视频模型升级：Agnes-Video-2.5-preview

模型名称：Agnes-Video-2.5-preview，状态：即将上线。升级内容：

- 生成速度提升一倍
- 运镜更流畅
- 物理规律还原增强（漂浮、穿模、碰撞问题改善）
- 新增多参考图能力（人物和商品一致性更好）
- 字幕乱码问题改善

目标用户：广告投放、短视频矩阵等需要批量生产、快速试错的用户。

### 05: 社会反馈

用户反馈问题：
- 首 Token 响应时间有时不太理想
- 图片模型偶发 503 错误（高峰期不稳定）
- Codex 等客户端接入时配置不当可能出错

透明度：GitHub Issues 和 Projects 看板公开，可追踪 bug、功能排期和迭代进度。

## Summary

本文介绍了 Agnes AI 及其新产品 Pavo——一个 PC 端的一站式 AI 创作平台。Agnes AI 通过将文本、图片、视频三大模型 API 免费开放，单周调用量已达 5 万亿 Token。Pavo 的核心亮点有三：一是"剧情短片"工作流，将一句话需求转化为完整的短剧制作流水线（剧本→角色→分镜→成片）；二是 Agent 总指挥模式，用户一句话即可驱动广告片制作；三是即将上线的视频模型 2.5 版本，在速度、物理还原、角色一致性等方面均有提升。文章也指出了当前的问题，包括首 Token 延迟、高峰期稳定性等。

## Insight

这篇文章有几个值得留意的信号：

1. **免费 API 作为获客漏斗**。Agnes AI 用免费策略快速积累用户（单周 5 万亿 Token），再通过 Pavo 平台实现从"API 调用者"到"平台用户"的转化。这种模式本质上是用免费 API 做筛选和教育工作，为付费平台引流。

2. **"剧情短片"是差异化定位**。多数 AI 视频工具停留在单镜头生成，Pavo 尝试走通"剧本→角色→分镜→成片"的完整生产流水线。这相当于把创作门槛从"写提示词"降到了"写一句话需求"。但文章也坦承目前质感达不到电影级——这是整个赛道的共性瓶颈。

3. **Agent 作为创作流程的总指挥**。Pavo 的 Harness 框架将复杂创作任务拆解成多个子步骤，由 Agent 协调执行、用户逐节点确认。这和文境的 Workflow Index 设计思路相似——不是一次性生成最终结果，而是在每个步骤中由 AI 执行、人确认，再推进。

4. **与知识管理同频的趋势**。Agnes AI 解决的是"AI 工具碎片化"问题（集成多模态到一个工作流），和你做的"AI + Obsidian —— 知识管理工具集成"方向同频。不同的是，它集成的是内容创作流程，你集成的是知识管理流程。两者在"一站式整合"这个趋势上交汇。

5. **对标自身创作的思考**：如果你未来要做 AI 相关的抖音内容，Pavo 的剧情短片工作流也许是一个低门槛的短视频制作选项——从灵感到素材到成片在一个工具内完成，减少了切换成本。
