# 三人组：沉默的将军 · 军师 · 孩子

## 结构

```
沉默的将军 ──补丁关系──→ 会哄人的军师
     │                        │
     │ 沉默 + 缺席             │ 过度共情 + 超额反馈
     │                        │
     ↓                        ↓
      被共情坏了的将军的孩子
```

三个人物互相强化彼此的行为模式。没有人故意伤害谁——他们都在用自己的方式爱对方，而正是这些方式，让彼此越来越远。

## 核心冲突

将军不会哄人→孩子得不到正常的情绪反馈→转向军师→军师用战场级别的共情回应→孩子被喂出超出伤口的期待→军师无法一直满足→孩子愤怒→将军觉得孩子矫情→更沉默。

这个循环里没有坏人。每个人的行为都是前一个人行为的合理结果。

## 适用叙事

- 家庭/团队内部的情感断裂
- 代际创伤的传递
- "爱的方式不对"的悲剧
- 需要外部事件打破循环才能修复
